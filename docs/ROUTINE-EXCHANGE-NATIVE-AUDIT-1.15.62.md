# Routine exchange native acceptance and correction — 1.15.62 / Android98

This follow-up implements the user's request to test with Microsoft Excel and their physical Pixel. It builds on published 1.15.61, whose browser and serialized-file acceptance did not prove these native flows. Source and publication evidence are recorded in the release audit when the checks complete. Synthetic artifacts and private QA backups remain ignored under `.tools/routine61` and `.tools/routine62`; no personal data is committed.

## Failure reproduced on the Pixel

On a physical Pixel 10 running Android17/API37, the 1.15.61 QA app's global preference was Same reps. A repeated exercise instance retained `backoffRepsMode: increased`. Its preview/export showed Top6–8 and Back-off8–10, but starting the actual workout chooser produced Back-off6–8. All sets remained pending and no completed workout was created. Process kill/reopen offline preserved the pending entries. This revealed a presentation/runtime mismatch missing from the previous acceptance tests.

The global preference intentionally owned unmarked automatic mode/offset snapshots since 1.15.46. Simply making every old snapshot an exception would reinterpret existing routines and break later Settings changes. The correction therefore adds optional prescription intent: `backoffRepsOverride: true` denotes an explicit Same/+2/legacy-offset exception; unmarked/false prescriptions retain global inheritance. Manual `autoBackoffReps:false` ranges retain their existing independent behavior. The normal helpers, store update and historical identities remain in place; no storage migration is required.

JSON keeps version1 and does not infer exception intent from an older unmarked mode. New Excel exports show `inherit` for globally owned automatic prescriptions and preserve the old raw snapshot in metadata. Choosing `same`, `increased` or `legacy:N` explicitly marks the exception; choosing `inherit` clears it. Unchanged older workbooks remain compatible. The editor exposes the same Follow app setting/Same/Increased choice and preserves imported legacy exceptions through Save. Preview/PDF use the effective runtime rule.
