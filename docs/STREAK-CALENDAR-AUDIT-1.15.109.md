# Streak calendar 1.15.109 / Android 145

This release retains the collapsed color key, integrated local profile and optional profile-aware PNG/PDF exports introduced in 1.15.108. It corrects the final visual-review findings: complete month names now fit on one line with the photo visible, and long local names remain within three lines in both Chromium and WebKit.

The period's activity count sits above its selector, with the avatar to the left. The chosen name and current streak remain above that block. September/Septiembre, narrow screens, leap years, keyboard disclosure, visibility/reload and exported photos are covered in the compiled and public browser matrices. The complete local name remains available in the button title and accessible name.

Only calendar CSS and version metadata change from 1.15.108. Workout history, streak rules, local dates, identity, the profile visibility preference and the separate current/best/period counters retain the same behavior. The user authorized GitHub publication without a physical Pixel test. Native iPhone/iOS and phone installation are not claimed. Update-topic broadcasts are suppressed.
