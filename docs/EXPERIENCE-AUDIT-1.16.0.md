# TGym 1.16.0 experience and release audit

Runtime source: `2d2c32878cd9889d851c1ec72fb7ff34e172a63a`. Android versionCode: **153**. Published: 2026-11-04T19:09:08Z.

## Changes

History exercise details open after a **0.5-second hold** or the existing expand control. Weight, reps and RIR share a row; saved warm-up, Top, Back-off and working roles retain their recorded order and units. Incomplete taps and scrolling cancel a hold.

Report creation shows actual phase/page progress from **0 to 100%**, including a visible completion state and direct History CSV feedback. Complete-year selectors describe their actual report pagination. Download names contain the report title and creation date as **DD-MM-YY**, without TGym prefixes or extra range/section suffixes; slash separators cannot be used in portable file names. Titles are centered and product headers removed. Streak exports place training/best-streak metrics above a larger photo and name, remove explanatory/date clutter, and use a centered compact period and training count. Month tiles have centered month-only names. White or black backgrounds apply across Streak report periods. Consistency exports use centered titles/periods without the extra rest-day description. The green tracking-start indication appears only on pages that actually show that date.

Body Measurements exports reuse the app's anatomy with external leaders and a compact Before / After / Change table. The tested **13-measurement comparison fits one PDF page**; absent readings remain distinct from zero. This does not promise that every selected Stats dashboard or arbitrarily long report fits one page.

Profile opens read-only with a larger photo and the name beside it. Edit reveals name, photo and age controls; icon-only photo actions avoid extra labels. Save uses the atomic primary transaction, waits for its mirror, and leaves editing. Cancel discards profile drafts. Weight, height and goal open their established editors with separate Save actions; the removed Body measurements shortcut remains available in Stats. Duplicate submissions, primary-save failure and mirror retry are covered. The legacy height field stays in its selected display unit instead of being converted twice.

Replay App Tour now covers Nutrition, navigation, workout logging and automatic back-off sets, calendars, History detail access, Stats/body comparisons, reports, Profile editing, health connections, privacy, backups and offline readiness. The preview remains separate from live workout data and returns to the launching route. Withings uses optional server-side OAuth, private provider credentials and idempotent read-only imports into Body Weight, body composition and eligible height history. Manual records remain intact. Automatic imports run while opening/returning to TGym online; this is not a closed-PWA background service. A live account was not authorized during this audit: the owner must configure the server and consent. See [Smart scale setup](SMART-SCALE.md).

This feature release advances the semantic version from 1.15.116 to **1.16.0**, while Android code advances from 152 to **153**. Dev's prior core audit, AMOLED theme and Android-workflow corrections remain in the commit history and are included in the final source; no protected-main merge was performed.
